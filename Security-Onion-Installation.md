# Security Onion Installation and Configuration
## The following project walkthrough the installation of the Security Onion. 
Security Onion is a free and open Linux distribution for threat hunting, enterprise security monitoring, and log management. It includes a comprehensive suite of tools designed to work together to provide visibility into your network and host activity. 
## Installation Process
- First, download the ISO image from the [security onion website](https://docs.securityonion.net/en/2.4/download.html)
- Than, open your [VMware Workstation Pro](https://youtu.be/rDWKoFwvAkQ?si=LFb5s6JBl8nvU8El) on your host machine
