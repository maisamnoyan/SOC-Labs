# SOC-Labs
A repo of hands-on Security Operations Center (SOC) labs/projects. Each lab is a documentation of a tool or technique that a SOC analyst would use, from setup to configuration to the output. Projects are built and configured in a virtualized environment (Virtual Box or VMWare Workstation Pro) so that you can replicate and practice on your own machine.
